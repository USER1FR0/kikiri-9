# Kikiri-9: El Ultimo Pan

Auto-runner 2D para Unidad 2 ordinario (UTNG, GIDS6091).

## Requisitos

- Unity 6.3 LTS (6000.3.26f1) exacta
- Git LFS instalado (`git lfs install` una vez por maquina)
- Visual Studio 2022 Community o Rider

## Setup

1. Clonar: `git clone <url>`
2. `cd kikiri-9 && git lfs pull`
3. Abrir con Unity Hub seleccionando 6000.3.26f1
4. Primera apertura hace Reimport All (varios minutos)
